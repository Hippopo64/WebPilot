# WebPilot (starter)

Petit projet d’automatisation web (Playwright) pour ouvrir une page, faire un screenshot
et récupérer des liens. Dev Linux + VS Code.

## Prérequis
- Python 3.8+
- venv activé: `source .venv/bin/activate`

## Installation
```bash
pip install -r requirements.txt
python -m playwright install
